# Anthropic IPO Assessment

An analysis of Anthropic, PBC's preliminary prospectus (Form S-1/A No. 2, dated November 10, 2026), set out in the same format as a companion SpaceX IPO assessment. Each claim is tagged `[STATED]` (what the filing says, with page cites) or `[INFERENCE]` (the analyst's own judgment).

**Disclosure:** this assessment was prepared by Claude, an AI model made by Anthropic, the subject company. Check every figure against the filing. Not investment advice.

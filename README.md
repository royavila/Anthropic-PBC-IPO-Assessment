# Anthropic IPO Assessment

An analysis of Anthropic, PBC's preliminary prospectus (Form S-1/A No. 2, dated November 10, 2026), set out in the same format as a companion SpaceX IPO assessment. Each claim is tagged `[STATED]` (what the filing says, with page cites) or `[INFERENCE]` (the analyst's own judgment).

**Disclosure:** this assessment was prepared by Claude, an AI model made by Anthropic, the subject company. Check every figure against the filing. Not investment advice.

## View the web version

Enable GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**. The page will be served at `https://<your-username>.github.io/<repo-name>/`.

## Read-aloud

Press **Listen** in the bar at the top of the page. You can also tap **Listen from here** on any section, or tap a paragraph while it is playing to jump to it. Speed and voice are adjustable.

The voice comes from the viewer's device, so it varies. On iPhone, Safari works best, and reading stops if the screen locks. The page needs an internet connection only to load the Google Fonts stylesheet.
